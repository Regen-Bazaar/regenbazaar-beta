# Coral fragments planted (`coral_planted`)

Methodology v0.2, Community layer. Domain: environment. Part of Regen Bazaar's own relative index; not a certification.

| Field | Value |
|---|---|
| Definition and unit | Coral fragments (nubbins) out-planted on a reef. Monitoring metrics follow the NOAA / Coral Restoration Consortium monitoring guide 2020. |
| Input unit / scored unit | fragments / fragments |
| What the weight represents | Reef habitat restoration per surviving fragment. No carbon or monetary value source exists. |
| Weight (points per fragments) | 0.4 |
| Anchor | Weight: none (v0.1 value 0.4 kept). Survival: Boström-Einarsson et al. 2020, PLoS ONE, 60–70% survival across restoration projects; midpoint 0.65. |
| Calculation | fragments × 0.4 × S 0.65 × ESM. Measured survival replaces 0.65. |
| Status | assumption (needs check). Source: v0.1 value; no carbon or value source for coral fragments |
| Survival factor S | 0.65, sourced. Source: Boström-Einarsson et al. 2020, PLoS ONE: 60–70% survival (midpoint) |
| Multipliers | SM (area factor): no, 1.0. ESM: yes, 1.0–1.3. Domain coefficient k: 1.0, pending cost survey |
| Sensitivity (±50%) | unstable (ranking moves at −50%: 4, at +50%: 0) |
| Five Dimensions rubric | depth 2, duration 2, vulnerability 2 → product 8; rubric-implied weight 0.36 (0.90× current) |
| Proof that fits | P2 dated underwater photos of the nursery and out-plant site; P3 dive centre or marine park confirmation; P4 survival monitoring data. |
| SDG tags (contributes to) | SDG-14 |
| v0.1 value | 0.4 per fragments |
